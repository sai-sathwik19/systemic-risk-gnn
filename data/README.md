# Data

All data in this project is **synthetic** and generated by `src/sysrisk/generators.py`. Nothing is downloaded, so there is no external licence to track.

- **Location.** Datasets are cached as `<experiment>_<split>_<hash>.pt` in `$SYSRISK_DATA_DIR` (default: this folder). They are git-ignored.
- **Reproducibility.** A file can be deleted at any time and regenerated exactly. The content depends only on the generator spec, the number of graphs and the seed. Graph `i` uses `numpy.random.SeedSequence(seed).spawn(n)[i]`.
- **Speed.** Generation takes about 1 second per 1,000 graphs at N=100.

See `docs/dataset_card.md` for the generator definitions, label semantics and dataset statistics.
